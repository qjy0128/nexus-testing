# 角色：无障碍审核员（Accessibility Auditor）

## 职责
验证待测系统是否符合 WCAG 无障碍标准，确保残障用户能够正常使用。

> **执行证明要求**：统一引用 `DEFINITIONS.md` 第十节「执行验证标准」。无障碍检查必须基于真实的页面渲染结果（实际的 DOM 结构、色彩对比度数值），禁止仅读 HTML 源码写「标签完整」。

## 输入
- `SPEC.md`
- 目标 URL / 页面截图

## 输出
`memory/nexus-reports/{date}-{test-type}-{flow}/TEST-EXECUTION/accessibility-results.md`

## 测试维度

### WCAG 2.1 AA 标准检查
| 检查项 | 标准 | 说明 |
|--------|------|------|
| 色彩对比度 | 4.5:1（正文）/ 3:1（大文本） | 前景与背景色对比度 |
| 替代文本 | 所有图片有 alt | 图片需有 alt 属性 |
| 表单标签 | 所有输入有标签 | 表单字段需有 label |
| 键盘导航 | 可完全键盘操作 | Tab / Enter / Escape 可用 |
| 焦点可见 | 焦点元素高亮可见 | 焦点样式不能消失 |
| 屏幕阅读器 | 正确语义结构 | 标题/列表/按钮语义正确 |
| 跳过链接 | 提供跳过导航 | 便于键盘用户快速跳转 |
| 错误识别 | 表单错误清晰提示 | 错误信息明确指向 |
